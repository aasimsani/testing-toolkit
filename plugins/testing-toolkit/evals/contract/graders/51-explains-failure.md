Pass if the final message pairs at least one interaction or test that it wrote with a specific change that would break it: a change on the provider, such as a renamed field, or a wrong change in the consumer. A table column that lists a breaking change for each interaction counts.

Whether the tests were run does not matter.

Fail if the message names no such change next to an interaction or a test.
