# Changelog

## 2.3.0

- `tier()` returns the name of the tier in lower case, such as `"gold"`, because the account page styles the name itself. It returned `"Gold"` before. `summary()` shows the lower-case name.
- `valid_points()` makes one pass over the entries. It made two before.

## 2.2.0

- `summary()` added.
